## Relatando Vulnerabilidades

Se você identificar qualquer vulnerabilidade de segurança, integridade estocástica ou exposição de dados no **Cartela**:
1. Não abra uma issue pública.
2. Envie um e-mail confidencial para o mantenedor responsável com detalhes e reprodução:
   - **Contato:** `alessandro.meneses@Enterprise.com`
3. Nossa equipe responderá em até 48 horas com uma análise preliminar e plano de mitigação.
